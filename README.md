# SkyPort ✈️  
### Smart Airport Companion Application

SkyPort is an Android-based airport companion application designed to simplify and enhance the air travel experience. The app provides users with flight booking, digital ticket management, airport service discovery, and future-ready airport navigation features — all within a clean and user-friendly interface.

---

## 📱 Features

- ✈️ Flight Search & Booking
- 🎫 Digital Ticket Management
- 🏪 Airport Shops & Restaurant Discovery
- 🧭 Planned Interactive Airport Navigation
- 👤 User Authentication & Profile Management
- 💳 Payment Integration Flow
- 📍 Airport Service Recommendations
- 📶 Offline-capable JSON-based Data Handling

## 📂 Project Structure

```bash
SkyPort/
│
├── activities/        # Activities & Screens
├── fragments/         # UI Fragments
├── adapters/          # RecyclerView Adapters
├── models/            # Data Models
├── repository/        # Data Handling Layer
├── viewmodels/        # MVVM ViewModels
├── utils/             # Utility Classes
├── res/
│   ├── drawable/      # Icons & Graphics
│   ├── layout/        # XML Layout Files
│   ├── values/        # Colors, Themes, Strings
│   ├── navigation/    # Navigation Graph

```
